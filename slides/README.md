# One design system, better Giga products — slide deck

A zero-dependency, 16:9 HTML slide deck presenting Giga's move from IBM Carbon to
its own shadcn-based design system.

- **File:** `index.html` — open directly in any modern browser, or deploy the `slides/` folder.
- **Design:** built in the Giga design language — Manrope / Open Sans, Giga blue (`#277aff`),
  connectivity status colours, 6px radius, soft shadows, and a dark-mode GigaMaps slide.
- **Assets:** `assets/` holds the Giga + Digital Inclusion logos referenced by the deck.
- **Navigation:** arrow keys / space / on-screen controls / swipe. Dots jump to any slide.
- **Live embeds:** slides 6, 7 and 9 embed the live product demos
  (`devmap-giga.vercel.app`, `gmeter-test-di-design-system-github.vercel.app`,
  `giga-kit-products.vercel.app`). Each shows a branded placeholder until the embed loads.
- **Footer:** every slide carries the UNICEF Digital Inclusion logo.
